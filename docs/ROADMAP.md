## 2. 下一阶段优先级

### P0：把“研究结果”变成“每日可运行”

1. **增量数据与调度**
   - 每日 17:30 增量摄取 → 重建面板 → 生成信号 → 邮件/飞书推送；
   - 数据质量校验（缺失率、涨跌幅异常、复权因子跳变）。
2. **因子衰减监控**
   - 滚动 6 个月 IC，低于阈值触发 `WATCH`；
   - 组合权重按近期 IC 衰减动态降权；
   - 与注册库的 `created_at` + 评估快照联动。
3. **历史行业分类**
   - 接入申万/中信行业历史成分（`index_member` 的行业版本），替换当前快照，消除行业前视。

### P1：组合与风险

1. **Barra-lite 风险模型**：CNE5/CNE6 的 10 个风格因子（规模、Beta、动量、残差波动、非线性市值、B/M、流动性、E/P、成长、杠杆）+ 行业；
2. **带约束的组合优化**：最大化 `scoreᵀw − λ·turnover − γ·wᵀΣw`，约束行业暴露、单票上限、跟踪误差、换手；
3. **容量与冲击成本**：按 ADV 分档估计冲击成本，替代固定滑点。

### P2：挖掘

1. **GP 增强**
   - 质量-多样性（MAP-Elites / 分层进化，参考 AutoAlpha）；
   - 种群级去重与相关性惩罚（当前只在 Hall of Fame 过滤）；
   - 多目标：IC、ICIR、换手、与存量因子相关性。
2. **RL / AlphaGen**
   - 接口已预留（`mining/`）；下一步接 PPO，以下游组合表现为 reward，输出协同因子集合；
   - 需要 GPU 环境（当前环境无 torch，未安装）。
3. **RD-Agent(Q)**
   - 用多智能体自动生成“假设 → 表达式 → 评估”；
   - 复用 `FitnessEvaluator` 作为工具，生成结果写入注册库。

### P3：产品化

1. **Web 控制台**（FastAPI + 前端）：✅ 已交付 v0.2
   - 总览 / 因子库 / 在线表达式评估 / 回测 / T0 事件 / GP / Qlib / 数据源；
   - 因子详情抽屉、源探活与数据湖行数；
   - 下一步：任务队列、回测对比、多用户/权限。
2. **实验管理**：MLflow（Qlib 已带依赖）记录因子、参数、回测、审计快照；
3. **模拟盘/实盘**：Qlib `OnlineManager` 或自建执行网关；申报频率监控对标 300 笔/秒、2 万笔/日红线；
4. **多市场/多频率**：日频 → 30 分钟/5 分钟；ETF/可转债/期货扩展。

## 3. 不建议现在做的事

- 在全市场 5,000 只上直接跑 158 因子 × 逐日 GP：算力与过拟合都会失控；先用 300–500 只确定性股票池做研究。
- 用日频重叠 IC 的 ICIR 直接对标月度 0.5 阈值：会系统性高估。
- 在未做 PIT/审计前追求高 IC：平台已经把审计做成默认输出，不要绕过。
- 用最新指数成分回测历史：股票池已用历史成分并集，保持这一纪律。

## 4. 验收清单（下一里程碑）

- [ ] 每日增量任务连续运行 20 个交易日无人工干预
- [ ] 因子注册库中 ≥20 个因子有完整 Train/Valid/Test 快照
- [ ] 组合月度换手 ≤ 8×，扣费后跑赢基准
- [ ] 事件组合在 3 个滚动年度上不出现单年 -30% 以上回撤
- [ ] 审计：任一因子都能在 T0−1 截断重算复现
- [ ] 一键生成日报（HTML/邮件）
