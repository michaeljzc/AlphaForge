# 组合回测：原理、选股与组合构建

一句话：**先由多个因子合成一个截面总分，再按总分排序选 Top-N，等权买入，次日开盘执行，持有到下一次调仓**。
不是“每个因子单独下单”，也不是均值-方差优化器，而是一个**月频多因子打分组合**。

```text
因子矩阵 (T×N)
  └─ 每个因子：去极值 → 截面 Z-score → 行业 + 市值中性化
      └─ 训练期 IC 定方向、定权重
          └─ 合成 composite score
              └─ 股票池过滤 → 按分数排序 → Top-N + 缓冲 + 行业上限
                  └─ 等权目标权重
                      └─ t 收盘出信号，t+1 开盘撮合
                          └─ 逐日盯市 → 净值 / 回撤 / 换手 / 超额
```

代码入口：

- 因子合成：[`combine_factors()`](src/alphaforge/portfolio/combine.py#L31)
- 选股：[`_pick_names()`](src/alphaforge/portfolio/combine.py#L88)
- 目标权重：[`build_targets()`](src/alphaforge/portfolio/combine.py#L125)
- 撮合：[`Broker.rebalance()`](src/alphaforge/backtest/engine.py#L226)
- 回测主循环：[`run_backtest()`](src/alphaforge/backtest/engine.py#L266)
- 演示参数：[`demo.py`](src/alphaforge/pipeline/demo.py#L141)

## 1. 因子如何变成“一个分数”

### 1.1 单因子预处理

每个因子先在截面上做三步（[`preprocess()`](src/alphaforge/preprocess.py#L93)）：

1. **MAD 去极值**：`median ± 3×1.4826×MAD`，抑制 A 股厚尾；
2. **截面 Z-score**：`(x - mean) / std`；
3. **行业 + 市值中性化**：对 `log_mv` 和行业哑变量回归取残差。

所以进入组合的是“剥离了行业和市值暴露后的标准化因子值”。

### 1.2 IC 定向与加权

演示使用 `method="ic_weighted"`：

- 在训练期 **2021-01-01 ~ 2023-12-31**，计算每个因子与未来 5 日收益的截面 RankIC；
- 因子方向：`sign = +1 if mean(IC) ≥ 0 else -1`；
- 因子权重：`weight = |mean(IC)|`，再归一化到总和为 1；
- 合成：

\[
S_{i,t} = \sum_k w_k \cdot \operatorname{sign}(IC_k) \cdot z_{k,i,t}
\]

其中 \(z\) 是预处理后的因子值。最后对 \(S\) 再做一次截面中性化。

本机 30 个默认因子的实际权重（训练期；这里的 IC 是训练期**日频**截面 IC 的均值，
不是闸门使用的月度 IC）：

| 因子 | 方向 | 权重 | 训练期日频均值 IC |
|---|---:|---:|---:|
| `volatility_20` | -1 | 11.3% | -0.0407 |
| `bp` | +1 | 9.9% | +0.0359 |
| `ep` | +1 | 6.6% | +0.0238 |
| `amihud_20` | +1 | 5.3% | +0.0193 |
| `ma_ratio_20` | -1 | 5.3% | -0.0191 |

> 负 IC 因子不会“剔除”，而是反向使用。例如 `volatility_20` 的 IC 为负，意味着低波动股票未来收益更高，因此 `sign=-1`，低波动会得到更高的综合分。

### 1.3 与因子闸门的关系

闸门（IC/ICIR/单调性/扣费）用于**研究与入库判断**；组合默认使用 `default_factor_names()` 的 30 个因子，
并**不是只使用 PASS 的因子**。当前只有 `volatility_20` 通过闸门，但它在组合中权重最高。
如果要“只用 PASS 因子”，需要把 `combine_factors` 的输入列表改成 `[r.name for r in reports if r.verdict == 'PASS']`。

## 2. 如何通过因子筛选股票

选股不是逐因子设阈值，而是**按合成总分排序**（[`_pick_names()`](src/alphaforge/portfolio/combine.py#L88)）。

### 2.1 先做股票池过滤

`eligible` 来自 `panel.mask("universe")` 与 `score` 有限值：

- 指数历史成分（CSI300 + CSI500 并集）；
- 上市满 60 个交易日；
- 价格 ≥ 1 元、成交额 ≥ 500 万元；
- 非停牌、非 ST 代理；
- 因子值有效（非 NaN）。

### 2.2 再按分数排序

```text
order = argsort(-score)        # 分数从高到低
先保留老持仓中仍在前 top_n+buffer 名的股票
再按 order 补足到 top_n
```

演示参数（[`default.yaml`](configs/default.yaml#L102)）：

| 参数 | 值 | 作用 |
|---|---:|---|
| `top_n` | 50 | 目标持仓数 |
| `buffer` | 10 | 老持仓只要还在前 60 名就优先保留，降低换手 |
| `max_weight` | 5% | 单票上限；50 只等权时实际为 2% |
| `max_per_industry` | `max(3, ceil(50×0.25)) = 13` | 单行业最多 13 只 |

> 注意：这里的行业约束是**只数上限**，不是行业暴露约束。`build_targets` 没有使用
> `max_industry_dev`；真正的行业中性发生在因子预处理阶段，组合层面只是防止极端扎堆。
> 实测第一个调仓日：50 只、每只 2%、行业最多“电气设备”10 只（低于 13 的上限）。

### 2.3 权重：等权，剩余留现金

```python
w = min(1.0 / len(names), max_weight)
```

- 50 只 → 每只 2%，满仓；
- 40 只 → 每只 2.5%，满仓；
- 少于 20 只 → 单票被 5% 上限截断，剩余权重留现金。

组合不做 score 加权、不做风险平价、不做均值-方差优化。

## 3. 回测如何执行

### 3.1 时间轴

```text
t 收盘：计算因子 → 合成 score → 生成目标权重
t+1 开盘：按目标权重交易
t+1 收盘：按收盘价盯市
...持有到下一次调仓...
```

演示为**每 21 个交易日调仓一次**（`rebalance_days=21`），区间 2024-01-02 ~ 2026-10-30。

### 3.2 撮合顺序与约束

[`Broker.rebalance()`](src/alphaforge/backtest/engine.py#L226) 先卖后买：

**卖出**
- T+1：当天买入的股票当天不能卖；
- 跌停/停牌不能卖；
- 单票单日不超过成交额的 10%；
- 100 股整手；
- 当前权重高于目标 1% 以上才卖（减少碎单）。

**买入**
- 涨停/停牌不能买；
- 100 股整手；
- 现金不足时按可用现金缩量；
- 当前权重低于目标 1% 以上才买；
- 按目标权重从大到小处理（等权时顺序无关）。

**被阻塞的订单**
- 涨停买不进、跌停卖不出、停牌：进入 `deferred_buy` / `deferred_sell`；
- 后续交易日只重试这些被阻塞的标的，**不会每天全仓再平衡**；
- 下一次调仓时清空延迟队列，换新目标。

### 3.3 成本

| 成本 | 默认 |
|---|---:|
| 佣金 | 万三（双边，最低 5 元） |
| 印花税 | 万五（仅卖出） |
| 滑点 | 万五（买卖各一次） |
| 成交额占比 | 单票单日 ≤ 10% |

价格使用前复权价；持仓按股数 × 收盘价盯市，现金扣减费用。

### 3.4 绩效

[`compute_metrics()`](src/alphaforge/backtest/engine.py#L315) 输出：

- 总收益、年化收益、年化波动、夏普；
- 最大回撤、Calmar；
- 年化换手、交易笔数；
- 相对基准（沪深300）的超额、信息比率、Beta；
- 月度收益与月胜率。

本机演示（2024-01 ~ 2026-10，30 因子、21 日调仓、Top-50）：

| 指标 | 值 |
|---|---:|
| 总收益 / 年化 | 27.2% / 9.3% |
| 夏普 | 0.53 |
| 最大回撤 | -18.0% |
| 年化换手 | 11.5× |
| 超额收益 / IR | 9.5% / 0.30 |
| 月胜率 | 55.9% |

## 4. 为什么这样设计

1. **A 股中低频**：3–10 天到月频，避开高频监管与算力竞争；
2. **可解释**：每个因子有表达式和 IC/闸门，组合权重可追溯；
3. **抗换手**：Top-N + 缓冲 + 1% 交易带 + 只重试阻塞单，换手从“每日全仓再平衡”降到 11.5×/年；
4. **先研究后优化**：在因子没有稳定 IC 之前，上均值-方差优化只会放大噪声。

## 5. 已知局限 / 可以继续改的地方

- **没有组合优化器**：等权、无协方差、无跟踪误差/风险预算；`portfolio.optimize` 尚未实现。
- **行业约束是数量上限**，不是行业暴露中性；`max_industry_dev` 配置未真正生效。
- **因子权重固定**在 2021–2023 训练期，没有滚动再估计；因子衰减时不会自动降权。
- **没有个股止损/止盈**；持有到下一次调仓，靠延迟订单处理涨跌停/停牌。
- **回测撮合是日频近似**：开盘价 + 滑点、成交量占比上限；没有盘中冲击成本、集合竞价、融券约束。
- **基准是沪深300**，策略股票池是 300+500 并集，超额口径不是严格的同池基准。
- **组合只使用 30 个默认因子**；WQ101 目前只入库评估，没有自动进入组合。
