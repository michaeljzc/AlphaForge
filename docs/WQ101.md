# WorldQuant 101 Formulaic Alphas

来源：`101factors.pdf`（Zura Kakushadze, *101 Formulaic Alphas*, 2015）Appendix A。
平台已将 101 条公式全部转译、注册并跑通评估。

- 因子名：`wq001` … `wq101`
- 类别：`wq101`
- 表达式：`src/alphaforge/expr/wq101_formulas.json`（从 PDF 提取的原始公式）
- 转译器：`src/alphaforge/expr/wq101.py`
- 注册：`src/alphaforge/expr/library.py` 导入时自动注册

## 1. 转译映射

| WorldQuant | AlphaForge DSL |
|---|---|
| `rank(x)` | `cs_rank(x)` |
| `correlation(x,y,d)` | `ts_corr(x,y,d)` |
| `covariance(x,y,d)` | `ts_cov(x,y,d)` |
| `stddev(x,d)` | `ts_std(x,d)` |
| `sum/product(x,d)` | `ts_sum/ts_product(x,d)` |
| `decay_linear(x,d)` | `ts_decay_linear(x,d)` |
| `signedpower(x,a)` | `signed_power(x,a)` |
| `indneutralize(x, IndClass.*)` | `cs_indneutralize(x)`（按 `Panel.industry_id`） |
| `adv{d}` | `ts_mean(amount, d)`（美元/人民币成交额） |
| `cap` | `circ_mv`（流通市值） |
| `returns` | `ret` |
| `min/max(x, d)`（d 为数） | `ts_min/ts_max(x, floor(d))` |
| `min/max(a, b)`（b 为表达式） | 逐元素 `min/max(a,b)` |
| `x ? y : z` | `where(x, y, z)` |
| `a || b` / `a && b` | `or(a,b)` / `and(a,b)` |
| `scale(x, a)` | `cs_scale(x) * a`（默认 a=1） |

非整数窗口按论文定义向下取整（`floor`）；例如 `correlation(...,3.92795)` 用 3 日。


## 3. 口径与局限

1. **行业中性化**：论文的 `IndClass.sector/industry/subindustry` 被折叠为当前
   `Panel.industry_id`（Tushare 行业快照）；没有历史行业变更链，存在轻微前视。
2. **adv**：用成交额均值，而不是成交量；A 股以人民币计价，量纲与美股不同，但
   `rank/correlation` 等对量纲不敏感。
3. **cap**：用流通市值；论文通常是总市值。对 `rank(cap)` 类公式影响很小，
   对绝对规模项可能有差异。
4. **ts_argmax/ts_argmin**：返回窗口内位置（0=最早），用于 `rank` 时只依赖相对排序；
   与某些实现的 1-based 返回不同，但方向一致。
5. **scale**：`cs_scale` 使截面 `sum(abs(x))=1`，再乘 `a`；与论文一致。
6. **评估**：全部因子走 AlphaForge 的月度 IC 闸门（|IC|>0.03、|ICIR|>0.5、
   方向扣费后收益>0 等）。101 个原始因子不可能都通过；批量结果会保留真实值，
   不做筛选性展示。

## 4. 批量结果

运行 `alphaforge factors batch --category wq101` 后：

- `reports/artifacts/factors/index.json` 会合并 101 个快照（不会覆盖已有 30 个）；
- Web「因子库」可按类别 `wq101` 筛选、点击查看 IC/分层/闸门/表达式；
- 详细结果见 `reports/wq101_batch.log`。

### 本机实测（2021-01 ~ 2026-10）

| 项 | 结果 |
|---|---|
| 注册 / 评估 | 101 / 101，全部解析并完成评估 |
| 覆盖率 ≥ 50% | 85 个 |
| \|IC(月)\| ≥ 0.03 | 1 个（`wq095`，但覆盖率仅 0.2%，闸门 WATCH） |
| 覆盖率正常且 IC 较高 | `wq040` IC 0.0294 / ICIR 0.97，`wq088` 0.0275 / 0.89 |
| PASS | 0 个 |

`wq095` 是布尔型公式，只有极少数交易日的取值有截面差异，因此月度 IC 虽然高，
但覆盖率和样本期数都不达标；平台把它标为 `WATCH` 而不是 `PASS`，这是闸门在起作用。

## 5. 新增因子的建议

- 先看 `wq101` 中 IC 方向与 A 股逻辑一致的（反转、量价背离、行业相对强弱）；
- 与现有 `price_volume`/`launch` 因子做相关性去重；
- 在 T0 事件截面上重新评估，而不是直接套用全市场日历截面结论；
- 注意 2015 年美股样本的因子在 A 股 2021–2026 可能已衰减，闸门结果比公式本身更重要。
