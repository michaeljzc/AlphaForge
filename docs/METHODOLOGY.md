# 方法论

## 1. 点时数据（PIT）

财务字段以 `(code, ann_date, end_date, value)` 存储。任意评估日 `d`：

1. 只保留 `ann_date <= d` 的记录；
2. 对每个 `(code, end_date)` 取 `ann_date` 最大的一次修订；
3. 在所有已披露报告期中取 `end_date` 最大的一个；
4. 该值即 `d` 时点可知的最新基本面。

实现见 `data/panel.py::_load_pit`。这避免了两种常见泄露：

- 用 `end_date` 对齐（报告期结束后 60–90 天才公告）；
- 用“最新修订值”回填所有历史（修订本身是未来信息）。

财务因子在事件特征中同样走该路径，审计会检查 `ann_date <= asof`。

## 2. 表达式语义

- **因果性**：时序算子只使用当前行及以前的数据；`ts_rank(x, w)` 在 `t` 行使用 `[t-w+1, t]`。
- **NaN**：`mean/std` 等使用有效样本数，`min_periods = ceil(0.6w)`（可配置）；停牌造成的空洞不会让整个窗口失效。
- **截面算子**：只在 `mask`（默认 universe）内排名/标准化；非股票池成员为 NaN。
- **标量广播**：`close / 100`、`where(cond, 1, 0)` 均合法。
- **Qlib 兼容**：`translate_qlib_expression()` 把 `Ref/Mean/Std/Rank/Greater/Less/...` 映射到本 DSL；`Greater`/`Less` 是逐元素 max/min（与 Qlib 语义一致），不是布尔比较。

## 3. 预处理

固定顺序：**MAD 去极值 → 截面 Z-score → 行业+市值中性化**。

- 去极值：`median ± 3 × 1.4826 × MAD`，对 A 股厚尾更稳健；
- 中性化：对每个截面做
  `f = a + b·log_mv + Σ c_ind·industry + ε`，取残差；
  实现用 FWL：先行业内去均值（同时处理 y 与 size），再对残差 size 回归；
- 不重复中性化；因子合成后只做一次。

## 4. IC 与闸门

- 日频 IC：每个交易日因子与未来 h 日收益的截面 Spearman 相关；
- **月度 IC**：把日频 IC 按月取均值，再计算均值/标准差/ICIR/胜率；
- 闸门用月度口径，因为调研报告的 0.03/0.5 是月度惯例；日频重叠样本的 ICIR 会被自相关放大；
- 报告同时给出 `t_stat` 与 `t_stat_overlap_adj`，后者按 `n/h` 折减有效样本；
- `|IC|` 与 `|ICIR|` 取绝对值，负 IC 因子在组合中自动反向。

闸门检查：

1. `|IC_monthly| ≥ 0.03`
2. `|ICIR_monthly| ≥ 0.5`
3. 方向命中率 ≥ 55%
4. `|monotonicity| ≥ 0.5`
5. 扣费后方向收益 > 0
6. 覆盖率 ≥ 50%
7. 样本月数 ≥ 24

## 5. 分层、换手与成本

- 五分组按因子截面百分位划分；Q1 为因子最小，Q5 最大；
- 多空 = Q5 − Q1；负 IC 因子用方向调整后的多空；
- 换手：Top 组相邻调仓日的成员变化率；
- 成本：`2 × turnover × cost_bps`（双边），默认 30bps；
- 复利曲线只用**非重叠**持有期（每 h 行取一次），避免把 5 日收益按日复利造成虚假爆炸。

## 6. 回测撮合

- 信号在 `t` 收盘生成，`t+1` 开盘成交；
- 涨停（open ≥ up_limit）不买，跌停（open ≤ down_limit）不卖；
- 停牌（volume=0 / 无收盘价）不交易；
- T+1：当日买入不可当日卖出；
- 100 股整手；单票单日 ≤ 成交额的 10%；
- 成本：佣金万三（最低 5 元，双边）、印花税万五（卖出）、滑点万五；
- 未能成交的订单进入延迟队列，只重试被阻塞的标的，避免每日全仓再平衡造成换手虚高。

## 7. T0 事件标签

以 T0 收盘价为基准：

- `label_max = max(high[T0+1..T0+60]) / close[T0] - 1`
- `label_mdd = min(low[T0+1..T0+60]) / close[T0] - 1`
- `label_ret = close[T0+60] / close[T0] - 1`
- `tier`：strong（max ≥ 200% 且 |mdd| ≤ 50%）、weak（max ≥ 60%）、negative。

在 60 日窗口下 200% 极稀缺（本样本 17/10,094），因此报告同时给出弱正样本率与 `label_ret` 分布；事件组合按 60 日固定持有。

## 8. 防泄露审计

`event/audit.py`：

1. 随机抽事件，把面板截断到 T0−1，重算特征，与缓存值比对（阈值 1e-4）；
2. 校验 `asof_idx = t0_idx-1 < t0_idx`、`entry_idx = t0_idx+1 > t0_idx`；
3. 抽查财务 `ann_date <= asof`；
4. 审计结果写入报告；任何一步失败，报告标红。

## 9. 已知偏差

- **行业分类**：当前快照，历史行业变更会造成轻微前视；
- **ST**：用主板 5% 涨跌停幅度代理，未接入名称变更链；
- **幸存者偏差**：股票池取历史指数成分并集，已缓解但未覆盖退市股全部数据；
- **复权**：前复权价格在超长回测中会受最新复权因子影响，收益口径正确但价格水平不用于绝对估值；
- **事件容量**：等槽位组合不考虑冲击成本的规模弹性，只做成交额占比上限；
- **事件标签截断**：数据末端 60 个交易日内的事件标签不完整，事件 IC 与分层需剔除末端样本；
- **当前 ST 名称过滤**：股票池构建剔除当前名称含 ST/退 的标的，存在轻微幸存者偏差；
- **多重检验**：GP 产出需在独立验证/测试期衰减；报告展示 Train/Valid/Test 三段，而非只报训练 IC。
